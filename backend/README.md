# KHUSHI OPTICS - Backend REST API Service

Production Express.js backend for the KHUSHI OPTICS Billing & Management System.

## Features
- **RESTful Endpoints**: `/api/auth`, `/api/customers`, `/api/products`, `/api/billing`, `/api/inventory`, `/api/reports`, `/api/settings`
- **Security Headers**: Powered by Helmet.js & CORS
- **Rate Limiting**: Configured with `express-rate-limit`
- **Logging**: Morgan & custom file logging
- **Health Check**: Endpoint at `/api/health`

## Commands
```bash
npm install
npm run dev
npm start
```
